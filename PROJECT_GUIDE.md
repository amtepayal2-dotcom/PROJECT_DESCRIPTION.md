🤖 Agentic Multi-Modal Intelligence Engine

About the Project

An AI-powered assistant built using Python, Streamlit, and Google's Gemini API. It supports text conversations, conversation history, and image understanding.

Features

- 💬 AI-powered text chat
- 🧠 Conversation history
- 🖼️ Image upload and understanding
- ⚡ Simple and interactive interface
- 🔑 Secure API key input

Technologies Used

- Python
- Streamlit
- Google Gemini API
- Requests
- Pillow

Installation

Install the required libraries:

pip install -r requirements.txt

Run the Project

Start the application using:

streamlit run app.py

API Key

Enter your Gemini API key in the application's password field when prompted. Never upload your API key to GitHub.
